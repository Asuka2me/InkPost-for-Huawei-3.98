# 华为 3.98 寸墨水屏本地传图
烧录完固件后，给他配置wifi（2.4g）和服务器地址：http://10.230.241.145:8765，端口是8765.
双击 `start.cmd`，浏览器访问 http://127.0.0.1:8765 。需要 Python 3 和 Pillow（当前电脑已安装）。选择图片，调整方向、留白/裁切、抖动，再生成预览。

此程序适用于 InkSight 的 `/api/render` 原始四色图片接口，并非 USB 串口传图程序。不烧录、不修改板上固件。接口按公开 InkSight 源码实现；用户所用第三方固件尚需实机验证。

首次使用需要：
1. 电脑和屏幕连同一个 Wi-Fi。电脑开发时在自己配置的wifi名字的地址是 `10.230.241.145`，重连可能改变，可用 `ipconfig` 查询。
2. 记录屏幕原服务器配置（当前串口显示 `http://ink.midimaster.top`），进入固件配网页面，把服务器改为 `http://电脑局域网IP:8765`。如果页面分开填写地址和端口，端口填 8765，避免重复拼接。
3. 保存后唤醒/重启设备，观察程序页面连接状态。首次运行若 Windows 弹出网络访问窗口，允许 Python 在当前网络接收请求。手机热点可能隔离客户端，此时换普通路由器网络。
4. 上传后需要按固件的刷新键，或等固件定时取图。当前日志为每 60 分钟刷新。程序不会通过串口强制刷新。

取图返回 105984 字节，编码为黑=0、白=1、黄=2、红=3，每字节从高位起打包四像素，768×552 或 552×768。预览不是实屏色彩校准。网页显示“发送”只代表图片已传输，不能证明屏幕完成刷新。

当前已确认 COM4 为 ESP32-C3；串口曾报告刷新完成约 17 秒；启动日志也出现 Wi-Fi 超时与色彩缓冲内存不足。若网络正常而刷新失败，需要继续核对第三方固件实现。
接口参考：https://github.com/krstc/InkSight_adapt_HUAWEI_eink （firmware/src/network.cpp 与 backend/core/renderer.py）。本工具为独立实现。
